# Madrid2flip（小米 18 背屏移植模块）

面向 **Xiaomi MIX Flip 2 (`bixi`, HyperOS 4 / Android 17)** 的独立 Xposed 模块，将小米 18 (`madrid`) 背屏中心（动态壁纸、AI 应用卡、Lumi 语音陪伴、相册轮播与个性签名）完整移植到 MIX Flip 2 外屏运行。

## 主要功能（v2.0.0）

- **多场景唤起与双开关控制**：支持合盖/展开/半折轻拍两下指纹键、轻敲背面、控制中心快捷磁贴开关背屏；App 内置「背屏引擎开关」「背屏显示开关」与实时状态横幅（同步半屏/全屏视口、触摸锁定、背面光感 lux 与接近传感器状态）；
- **弯折支架模式**：半展开时自动熄灭内屏、只亮背屏当桌面支架展示壁纸，展开/合盖立即恢复内屏；
- **半屏双摄对齐 ↔ 原厂全屏视口**：支持 `1208×738`（含实时 GPU 毛玻璃延展背板）与 `1208×1392` 全屏视口无缝切换（带平滑淡入淡出），以及三档翻转/弯折双摄避让；
- **官方背屏个性化增强**：官方「相册轮播」「壁纸与签名」拆分为半屏/全屏两组独立分区（全屏区按 `1208×1392` 真实比例预览裁切）；解锁直接选择图片、视频与 Live 实况图，支持四档播放模式（循环 / 点击重播 / 亮屏一次 / 仅播一次）；自动隐藏 Flip 2 不支持的背屏息屏显示与背屏截屏入口，官方引导左滑相机步骤可轻点跳过；
- **防误触与屏幕保护**：背屏触摸锁定（WMS 层防抢占焦点不收起内屏输入法）、独立后置光感自动亮度与上限保护、后置接近原始流（`33171124`）贴桌自动息屏、三档防烧屏位移、AI 应用卡社区下载与 Lumi 语音对话。

> **前置依赖**：需配合小米 18 背屏中心系统资源 KSU / Magisk 模块（`madrid_subscreen_port_v1.0.0.zip`）使用，请前往源码仓库 Releases 下载刷入：
> https://github.com/Aragamiz/Madrid2flip/releases
>
> 刷入资源模块、在 LSPosed 启用本模块（勾选默认推荐作用域）并在 KernelSU 授予 Root 权限后，重启设备即可生效。
